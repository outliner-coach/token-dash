1. **위 변경 사용자 수락 + main 푸시** — 코드는 main에 커밋됨. 앱에서 개요·Codex 탭 육안 확인이 남았다(화면 캡처 검증이 안 되면 기하 계산 코드 리뷰로 대체하고 기록한다).
2. **Sonnet 5 가격 문구 정정** — $2/$10이 정가로 확정됐는데 코드·화면 캡션·README 비용표에 "도입가" 잔재가 있다. (코드 작업, 이번 사이클 범위 밖으로 확정)
3. **전용 토큰 등록** — 사용자가 `claude setup-token` 으로 발급해 Keychain에 등록하면 세션을 다 꺼도 공식 %가 유지된다. (사용자 손)
4. **집 기기 로그 합치기** — 집 컴퓨터 `~/.claude/projects` 를 복사해 설정의 추가 경로에 넣으면 된다. 복사본 경로가 준비되는 대로 한다. (사용자 손)
5. **나눠주는 방식 결정** — 전달 경로와 업데이트 수단이 미정이다. 정해지기 전까지 자동 업데이트·외부 다운로드 경로를 코드에 넣지 않는다. (사용자 결정)
